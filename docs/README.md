# Krest Documentation

**Krest** is a privacy-first Web, Stellar/Soroban, and API analytics platform built for modern web applications and the Stellar ecosystem.

- **Live Dashboard:** `https://krest.kellon.xyz`
- **Live API & SDK CDN:** `https://api-krest.kellon.xyz`
